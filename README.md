# javascript-dom-classlist-events-assignment
A JavaScript DOM practice project covering element selection, event listeners, classList manipulation, mouse events, getElementsByTagName(), loops, and dynamic content highlighting. The project includes interactive buttons, image hover effects, notice highlighting, student rules, and course information sections.
## Features

- Interactive box styling using JavaScript
- Button click event using `addEventListener()`
- Image hover effect using `mouseover` and `mouseout`
- Dynamic button display using `classList.add()` and `classList.remove()`
- Notice Board with highlight functionality
- Student Rules highlighting
- Course Information highlighting
- Selecting elements using `getElementById()`
- Selecting multiple elements using `getElementsByTagName()`
- Using `for` loops to apply changes to multiple paragraphs
- Dynamic content changes using `textContent` and `innerHTML`
- CSS styling and animations for interactive elements
